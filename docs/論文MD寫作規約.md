# 論文 MD 寫作規約 v1

**目的：** 統一論文各章節 md 的寫作格式，讓 `build_thesis.py` 組裝腳本能簡單地對齊元智格式規範 A，避免腳本層為了相容各種寫法而越補越亂。

**對應元智格式：** 元智大學碩士論文格式規範 A（`元智格式規範/md/R-G-A00-new.md`）

**適用範圍：** `md/` 資料夾內所有論文本文 md 檔。問卷結構、大綱等支援文件不適用。

---

## 1. 章節標題層級對應

| 元智格式層級 | md 寫法 | 範例 |
|------------|--------|------|
| 第 N 章 | **不寫**，由 `build_thesis.py` 的 `CHAPTERS` 提供 | （無） |
| 第 N 節（X.Y） | `## X.Y 標題` | `## 5.1 RL 概念理解測驗分析` |
| 壹、（X.Y.Z） | `### X.Y.Z 標題` | `### 5.1.1 測驗設計與評分方式` |
| 一、（X.Y.Z.W） | `#### X.Y.Z.W 標題` | `#### 4.6.2.1 三層次的統計切法策略` |
| 1.（最深層） | `##### X.Y.Z.W.V 標題` | （極少用，依需求） |

**腳本自動轉換**：`build_thesis.py` 會把 md 寫的編號自動轉換為元智格式的「第N節 / 壹、/ 一、」（轉換開關在腳本 line 32–37）。

---

## 2. 標題禁用規則

- ❌ **標題不要加 bold**
  ```
  錯：### **5.1 標題**
  對：### 5.1 標題
  ```
  腳本會自動加粗，bold 是冗餘的，且容易混淆解析。

- ❌ **不要用純 bold 假冒標題**
  ```
  錯：**5.1.1 標題**
  對：### 5.1.1 標題
  ```
  純 bold 偽標題會讓腳本無法判斷層級。

- ❌ **md 內不要寫章名**
  ```
  錯：## 第三章 Rein Room 平台設計
  對：（不寫，由 CHAPTERS 提供）
  ```

---

## 3. 修辭分項（無編號小標）

允許用純 bold——這類沒有 X.Y.Z 編號的分項視為「subhead」層級，不歸入 (X.Y.Z) 子節體系：

```markdown
**（一）參數操作的直觀化**

正文段落...

**（二）決策過程的可見化**

正文段落...
```

常見用途：
- 4.6 內的 `**（一）測試資料排除**`
- 6.1 內的 `**（一）兩平台皆能支持⋯⋯**`

---

## 4. 圖

**唯一寫法：** 用 markdown image 語法

```markdown
![圖 X-Y　標題（用全形空格分隔）](../images/figX-Y.png)
```

**規則：**
- 編號與標題之間一律用**全形空格 `　`**，不用半形空格、不用冒號
- 子編號用 `3-1a` / `3-11a` 等小寫字母（如同一張圖的多個視角）
- 圖檔放 `images/`，命名 `figX-Y.png`
- ⚠️ **不要再加 bold figcaption**（`**圖 X-Y　標題**`）—腳本會自動產生圖說

**腳本處理：**
- 自動將 `圖 X-Y` 轉為「圖 1」「圖 2」⋯⋯（全文連續編號）
- 自動將圖說置於圖下方（規範要求）
- 12pt 粗體置中

---

## 5. 表

**標準寫法：** 表說（純 bold）+ 表體（markdown table）

```markdown
**表 X-Y　標題（用全形空格分隔）**

| 欄1 | 欄2 |
|-----|-----|
| 內容 | 內容 |
```

**規則：**
- 編號與標題之間一律用**全形空格 `　`**
- 表說在表體**之前**（規範要求表號表名列於表上方）
- 兩者之間留一個空行

**腳本處理：**
- 自動將 `表 X-Y` 轉為「表 1」「表 2」⋯⋯（全文連續編號）
- 表內的圖/表參照（如 cell 內提到「圖 3-1」）也會同步轉換
- 12pt 粗體置中（表說）；12pt 置中（表內文字）

---

## 6. caption 標點

| 寫法 | 結果 |
|------|------|
| ✅ `圖 X-Y　標題` | 全形空格分隔（規範） |
| ❌ `圖 X-Y：標題` | 冒號 |
| ❌ `圖 X-Y 標題` | 半形空格 |
| ❌ `圖 X-Y: 標題` | 半形冒號 |

**腳本兜底：** `normalize_caption_punct()` 會在 caption 與 md image alt 內自動把錯誤標點統一為全形空格。**正文內的「見圖 X-Y」「如表 X-Y」這類引用不動**（保留原寫法）。

---

## 7. 列表

- 一律用 `-` 開頭（不用 `*` 或 `+`）
- 編號列表用 `1.` `2.` `3.`

```markdown
- 第一項
- 第二項
- 第三項

1. 第一步驟
2. 第二步驟
```

---

## 8. 強調與行內 bold

- `**bold**` 僅用於：
  - 圖表 caption
  - 修辭分項（`**（一）xxx**`）
  - 句中強調關鍵詞
- 中文不用 italic（`*xxx*` 或 `_xxx_`）
- 行內 bold 範例：`本研究的核心發現為 **T5 自主超參完成率差距 61% vs 25%**`

---

## 9. 區塊

- `---` 用於章節分隔（會被腳本忽略）
- `>` blockquote 用於引用（少用）
- ` ``` ` code block 用於程式碼，**block 內任何字元都不會被腳本處理**

```markdown
\`\`\`python
def example():
    pass
\`\`\`
```

---

## 10. 不要使用

- HTML 標籤（如 `<br>`、`<div>`）— 跨工具不相容
- footnote 語法（`[^1]`）— 腳本不支援
- 內嵌 raw LaTeX（`$$...$$` block）— 影響跨工具相容；行內 `$x$` 可用於數學符號

---

## 11. 文件命名與路徑

```
md/
├── 第一章 緒論.md
├── 2.1 強化學習基本概念與教育潛力.md
├── 2.2 ...
├── 3.1 ...
├── ...
└── 6.4 發表與推廣建議.md

images/
├── fig3-1.png
├── fig3-1a.png      ← zoom-in 子編號
├── fig3-11a.png     ← 同主題 a/b/c/d/e 子圖
└── ...
```

**檔名規則：**
- 章節 md：`X.Y 標題.md`（章節編號 + 空格 + 標題）
- 圖檔：`figX-Y.png`（小寫 fig + 章-號）

## 12. 工具支援

| 工具 | 用途 |
|------|------|
| `build_thesis.py` | md → docx 組裝；自動套用元智格式（A4、邊距、字型、章節編號轉換、圖表連續編號、頁碼、首行縮排）|
| `migrate_md_format.py` | 把現有 md 對齊本規約（使用 `--dry-run` 預覽；不加旗標即實際寫入）|

## 13. 檢核清單（寫新章節時）

- [ ] 標題層級對齊規約（## / ### / ####）
- [ ] 標題沒加 `**bold**`
- [ ] 沒有純 bold 偽標題（`**X.Y.Z xxx**`）
- [ ] 沒寫章名（由 CHAPTERS 處理）
- [ ] 圖用 markdown image 語法
- [ ] 表用「**表 X-Y　標題**」格式 + 空行 + 表體
- [ ] caption 用全形空格分隔
- [ ] 圖檔依規則命名放 `images/`
- [ ] 跑一次 `python build_thesis.py` 確認無警告
