# 論文分析：《ML-Quest: A Game for Introducing Machine Learning Concepts to K-12 Students》

---

## **1. 通篇概述**
本文介紹了一款名為 **ML-Quest** 的3D教育遊戲，旨在向中學生引入機器學習（Machine Learning, ML）的基礎概念。遊戲以角色扮演（RPG）形式分為三個關卡，對應教授 **監督學習（Supervised Learning）**、**梯度下降（Gradient Descent）** 和 **K-最近鄰分類法（KNN Classification）**。其目標是通過寓教於樂的方式增強學生對 ML 的興趣，並降低數學公式對學生學習的壓力。

---

## **2. 教學方法**
### **1. 教學設計**
#### **遊戲主題與關卡設計**
1. **遊戲主題**：保護王國為背景，學生作為主角完成一系列挑戰。
2. **關卡設計**：
   - **第一關：監督學習**：
     - 迷宮挑戰，學生利用已知路徑完成未標註迷宮的導航。
     - 目標：理解監督學習的標註數據如何幫助模型訓練。
   - **第二關：梯度下降**：
     - 學生基於坡度提示選擇最佳路徑。
     - 目標：學習如何通過最陡下降法優化模型。
   - **第三關：KNN 分類**：
     - 學生需要在敵人到達前救助目標，模擬最近鄰分類的邏輯。
     - 目標：理解 KNN 的多數表決機制。

#### **教學輔助功能**
- **即時提示**：顯示當前狀態數據（如距離、得分）。
- **關卡結尾總結**：解釋 ML 概念與遊戲挑戰的聯繫。

### **2. 遊戲開發與技術**
- 使用 **Unity 3D** 開發，通過 **WebGL** 部署到 Simmer.io 平台。
- 結合「支架理論（Scaffolding）」逐步揭示 ML 概念。

---

## **3. 驗證方法**
### **1. 評估框架**
採用 **技術接受模型（TAM）**，從以下四個維度評估遊戲：
1. **易用性（Ease of Use, EU）**：遊戲的操作簡單程度。
2. **有用性（Usefulness, U）**：遊戲對理解 ML 概念的幫助程度。
3. **使用意圖（Intention to Use, I）**：學生是否願意再次使用。
4. **正確性（Correctness, C）**：遊戲挑戰是否準確映射 ML 概念。

### **2. 數據收集**
1. **問卷調查**：
   - 包含 12 個問題，採用 5 分 Likert 量表（1 表示「非常不同意」，5 表示「非常同意」）。
   - 問題示例：
     - 「使用 ML-Quest 能幫助我更容易學習機器學習概念。」
     - 「遊戲中的視覺化展示與 ML 概念相關聯。」

2. **學習成果測試**：
   - 測試學生對 ML 概念的理解程度。
   - 比較學生在關卡中的完成效率和挑戰次數。

3. **背景資料收集**：
   - 參與者的 ML 基礎知識與對 ML 的興趣。
   - 平台使用偏好（桌機/手機）。

### **3. 分析結果**
- **參與者背景**：
  - 23 名高中生，33.3% 有 ML 基礎知識，42.1% 對 ML 感興趣。
- **調查結果**：
  - 易用性得分：3.61，標準差：0.93。
  - 有用性得分：3.78，標準差：0.74。
  - 使用意圖得分：3.43，正確性得分：3.65。
- **學生反饋**：
  - 70% 的學生同意遊戲提升了對 ML 的理解。
  - 主要建議：改進角色移動速度和敵人提示的可見性。

---

## **4. 對 AI Reinforce Lab 的參考價值**
### **1. 教學設計啟發**
- 運用關卡設計，將 RL 概念分解為多個小型挑戰，逐步引導學生理解。

### **2. 視覺化與互動**
- 引入即時提示和關卡總結功能，幫助學生建立具體操作與抽象概念的聯繫。

### **3. 驗證方法應用**
- 使用 TAM 模型進行教學效益評估，結合問卷調查與背景資料分析學生的學習成效。

### **4. 擴展方向**
- 開發基於瀏覽器的學習工具，提升工具的可訪問性。
- 在 RL 教學平台中應用支架理論，逐步引導學生掌握複雜概念。

---

## **5. 結論**
ML-Quest 是一款成功引導學生學習 ML 基礎概念的遊戲化工具，對於 AI Reinforce Lab 的開發具有以下啟示：
1. 關卡設計與 AI 教學結合的有效性。
2. 可視化技術增強教學效果的應用。
3. 使用 TAM 模型進行效益評估的價值。
