## 4.6 數據分析方法

本節說明本研究於蒐集完前後測測驗、問卷、任務完成記錄與課堂觀察資料後，如何進行整理與統計分析，以檢驗第 4.1 節所提出之研究假設（H1～H3）。

整體而言，本研究採用**量化分析為主、質性分析為輔**之混合方法設計：

- 量化資料：強化學習理論知識前後測分數（8 題）、平台回饋量表（Likert 1–5）、心智負荷量表（1–10）、系統易用性量表（標準百分制）、五項任務（T1–T5）之完成率與完成時間。
- 質性資料：開放題回應、課堂觀察記錄表中之 insight 紀錄。

以下依序說明資料整理流程、量化資料分析方法、質性資料分析方法與整體詮釋策略。

### 4.6.1 資料整理與前處理流程

**（一）測試資料排除**

研究者於正式施測前以個人帳號測試 Google Form 系統運作，分析時統一排除此類測試資料，僅保留實際受試者之回應作為有效樣本。

**（二）Student ID 配對處理**

前後測配對以學生自行填入之 Student ID 為依據。考量學生於不同次填寫時可能出現格式差異（例如大小寫不一致、是否包含連字號或學號前綴字母），本研究對 Student ID 進行格式正規化（轉為大寫、去除空格與連字號、去除學號前綴字母）後再進行配對。配對成功者納入「組內配對」與「組間比較」分析。

**（三）測驗分數計算**

理論知識測驗 8 題每題 1 分，總分 0–8 分。

**（四）量表分數計算**

- 平台回饋量表：直接以 Likert 1–5 之原始分數計算各題平均。
- 心智負荷量表：取 6 項分量表（1–10）之平均作為整體心智負荷指標，並對六項分項分別進行組間比較。
- 系統易用性量表：依標準計分方式轉換——奇數題（1, 3, 5, 7, 9）原始分數減 1，偶數題（2, 4, 6, 8, 10）以 5 減該題分數，加總十題後乘以 2.5，得 0–100 之百分制分數。

**（五）作答品質檢核（straightlining 標記）**

對心智負荷量表、系統易用性量表與平台回饋量表等多題量表，本研究進行作答品質檢核。若發現受試者於整份量表中所有題項皆填同一分數（直線式作答，straightlining），視為可能未認真作答之標記樣本。本研究於 5.3 節以「全部後測樣本、排除直線式作答、配對樣本」三種樣本範圍呈現描述統計，作為敏感性分析。

**（六）任務完成記錄整理**

任務完成記錄表之處理方式於 4.5.3 節已說明。本研究以「是否完成」之二元指標為核心，分母採該日課程實際出席人數（Day 1 任務以 Day 1 出席人數為分母，Day 2 任務以 Day 2 出席人數為分母），以避免「在名冊上但未到課」之學生膨脹分母而低估完成率。

### 4.6.2 量化資料分析方法

本節說明本研究所採用之有效樣本範圍與量化資料檢定方法。

**有效樣本範圍**：所有量表推論統計皆以「**前後測皆完成且 Student ID 可成功配對**」之配對樣本為範圍（RR 組 n = 10、Colab 組 n = 12）；任務完成率與完成時間分析因記錄表所用識別碼與後測問卷不同而沿用全班有效人數為分母（5.2.2 節說明）。

**檢定方法之選擇**：本研究有效樣本數為 RR 組 n = 10、Colab 組 n = 12，未達常態分配檢定通常要求之樣本規模。考量小樣本下常態分配假設難以驗證，本研究採用**無母數統計檢定**作為主要分析方法（Nunnally, 1978; Cohen, 1988）：

- **組內前後測比較**：Wilcoxon signed-rank 檢定。
- **組間比較**（前測同質性、組間量表比較、組間增益分數比較）：Mann-Whitney U 檢定。
- **類別變項比較**（任務完成率）：卡方檢定，並於期望次數小於 5 時改用 Fisher exact 檢定。

**效果量報告**：為補充以 p 值判讀小樣本研究時容易忽略之實質差距資訊，所有檢定結果同步報告效果量。

- Wilcoxon 與 Mann-Whitney：r = |Z| / √N，依 Cohen（1988）經驗準則 r < .3 為小、.3 ≤ r < .5 為中、r ≥ .5 為大。
- 卡方檢定：Cramer's V，於 2×2 列聯表下 V = √(χ² / N)。

**描述統計**：同時呈現平均數（M）、標準差（SD）與中位數（Mdn），俾便讀者跨統計典範比對。

**顯著水準**：α = .05，標記方式為 p < .05 標 \*、p < .01 標 \*\*、p < .001 標 \*\*\*、p < .10 標 †（趨近顯著）、p ≥ .10 標 n.s.。

**統計分析實作**：以 Python 之 SciPy 套件實作（`scipy.stats.wilcoxon`、`scipy.stats.mannwhitneyu`、`scipy.stats.chi2_contingency`、`scipy.stats.fisher_exact`）。

#### 4.6.2.1 理論知識測驗之統計策略

本研究於理論知識測驗分析中採用以下三個層次：

**（一）前測同質性檢驗**

於介入前以兩組之配對樣本前測進行 Mann-Whitney U 檢定，檢驗兩組起點是否具可比性，作為後續組間比較之前提。

**（二）組內前後測比較（Wilcoxon signed-rank）**

對前後測皆完成且 Student ID 可配對之學生進行 Wilcoxon signed-rank 檢定，比較其前測與後測分數之差異。此方法控制了個體差異；於本研究中 RR 組配對樣本 n = 10、Colab 組配對樣本 n = 12，於檢定中前後測差值為 0 之配對將被排除，實際參與排名之配對數於結果章節明確標示。

**（三）組間增益分數比較（Mann-Whitney U）**

計算每位配對學生之增益（Gain = Post − Pre），以 Mann-Whitney U 檢定比較兩組增益分數之差異，呈現兩組學習成效之相對差距。

組內與組間之分析結果若方向一致則結論之穩健性較高；若存在分歧，則於詮釋時謹慎說明。

#### 4.6.2.2 量表資料分析

對平台回饋量表、系統易用性量表與心智負荷量表，以配對樣本為範圍進行 Mann-Whitney U 檢定組間比較，並報告效果量 r。心智負荷量表除整體平均外，六項分項分別進行檢定。為提供讀者跨樣本範圍之比對，於 5.3.6 節並列呈現「全部後測樣本」、「全部排除直線式作答」、「配對樣本」三種樣本範圍之描述統計，作為樣本範圍選擇對結果影響之敏感性分析。

#### 4.6.2.3 任務完成率與完成時間分析

**完成率**以卡方檢定（含期望次數小於 5 時改用 Fisher exact）比較兩組於各任務之完成率差異，效果量採用 Cramer's V。**完成時間**對有完成記錄之學生以 Mann-Whitney U 檢定比較兩組之完成耗時，效果量採用 r。

完成率與完成時間之分析皆以全班有效人數為分母。此一資料對齊限制（與量表分析使用之配對樣本範圍不同）於 5.2.2 與 5.2.5 節明確說明。

### 4.6.3 質性資料分析方法

量化分析可提供整體趨勢與顯著性檢定，但學生實際之學習歷程、困難點與對平台之細膩感受，往往需要透過質性資料補充說明。本研究之質性資料來源有二：開放題與課堂觀察記錄表，分析方法分述如下。

**（一）開放題之主題歸納**

開放題回應採主題歸納法（thematic synthesis）整理，步驟為：
1. 將兩組之開放題回應整理為文字檔，依組別與題項（6-1、6-2、6-3）分類。
2. 對回應進行初步閱讀，標記反覆出現之關鍵字與主題。
3. 將相似主題彙整為較高層次之類別。
4. 計算各主題於兩組之提及比例，並挑選代表性引文於論文中匿名引用。
5. 主動識別並保留負面回饋，避免僅呈現正面回應而扭曲結論。

**（二）課堂觀察記錄之對比分析**

兩組各兩堂課之觀察記錄表（共四份）依結構化欄位整理：

- 量化部分（四項三選一勾選）：將兩組之主動調參比例、討論熱度、視覺化反應、整體專注度製成對比表，呈現課堂動態之差異模式。
- 質化部分（學生 insight 與卡關點）：彙整為主題敘事，與開放題質性分析交互印證。

**（三）質性與量化之交互印證**

質性資料之主要功能為「**為量化結果提供解釋**」。本研究於 5.4 節中將課堂觀察、量表自評與任務表現三類資料對應同一現象進行串聯，呈現各層次資料間之方向關係。質性主題之提及比例（如「參數調整困難」於兩組之比例差距）亦與量化指標（如任務完成時間之顯著差距）並列呈現。

### 4.6.4 整體詮釋策略

本研究整體詮釋遵循以下原則：

**（一）多層次資料並列呈現**

研究結論之解讀同時參考行為（任務完成率與完成時間）、認知（前後測分數）、情意（量表）與質性（觀察、開放題）等多類資料。各層次資料於 5.x 與 6.1 節中分別呈現，並標示各指標之檢定結果與效果量，不以單一指標為結論依據。

**（二）統計顯著與效果量並重**

考量小樣本研究之檢定力限制，本研究於詮釋時同時呈現 p 值與效果量。對於 p 值未達 .05 但效果量達中等以上（r ≥ .3、V ≥ .3）之指標，於結果章節中以「描述上有差距、效果量達中等、惟於現有樣本規模下未達 α = .05 顯著水準」之方式陳述，避免「未達顯著即等同無差異」之過度簡化詮釋，亦避免「沒達顯著仍宣稱勝出」之過度詮釋。

**（三）研究限制透明呈現**

本研究於各章相關位置明確列出資料限制：5.1 配對樣本之 attrition 與天花板效應、5.2 任務完成記錄與後測問卷之識別碼對齊限制、5.3 直線式作答之處理、5.4 兩班自然差異與班級層級之未控制變項等。研究限制亦於第六章專節集中討論。

### 4.6.5 小結

本節介紹本研究於數據分析上之整體策略：

於**量化部分**，以配對樣本為範圍（n_A = 10, n_B = 12）採用 Wilcoxon signed-rank 與 Mann-Whitney U 等無母數檢定，並同步報告效果量 r；任務完成率採卡方檢定（含 Fisher exact）與 Cramer's V；任務完成時間採 Mann-Whitney U 與 r。

於**質性部分**，運用開放題主題歸納與課堂觀察結構化分析，補充說明介面特性、學習歷程與情意反應，並與量化結果並列呈現。

於**整體詮釋策略**上，本研究多層次資料並列呈現，統計顯著與效果量並重，並透明呈現研究限制。

透過上述多層次、多來源之分析，本研究期望全面理解視覺化互動式 RL 教學平台於大學階段教學情境中之優勢與限制，並為未來相關課程與系統設計提供參考。
