# 影片規劃與教學流程

**總影片數：18 支**
共用理論影片 × 6，各組專屬影片 × 6 × 2（平台導覽 1 + 遊戲示範 5）

---

## 一、理論影片（共用，兩組相同連結）

| 代號 | 標題 | 涵蓋內容 | 示範環境 | 位置 |
|------|------|---------|---------|------|
| V0 | What is RL — SAR Loop & Episode | Agent/Environment 互動循環、State/Action/Reward 定義、Episode 概念 | Maze1D（人物會動，SAR 對應直觀）| Day 1 最前 |
| V1 | How Agents Decide — ε-greedy & Hyperparameters | ε-greedy 策略、探索 vs 利用、**α / γ / ε 三個超參數全部介紹**（後續 TA 從 MAB 開始確認設定）| MAB（定不動 vs 反覆橫跳，最能凸顯貪婪行為）| Day 1，Platform 導覽後 |
| V2 | How Agents Learn — Q-table & Update Rule | Q(s,a) 定義、Bellman 更新公式、α 和 γ 深講 | Maze1D → Maze2D | Day 1，Maze1D 後 |
| V3 | Reading the Q-table Heatmap | 熱力圖顏色意義、箭頭方向、如何追蹤 Start→Goal 路徑 | Maze2D | Day 1 末尾（預習，Day 2 Maze2D 深探前置）|
| V4 | Reading Training Curves | Reward 曲線形狀判讀（平坦/上升/下降/噪聲）、收斂判斷、突降原因 | Heli（先平後升特徵最明顯）| Day 2，Heli 前 |
| V5 | Continuous State & Discretization | 連續 vs 離散狀態空間、bins 的意義與取捨、狀態爆炸問題 | Heli → Fighter | Day 2，Fighter 前 |

### 理論概念依賴鏈

```
V0: SAR + Episode
 └─→ V1: ε-greedy + α/γ/ε（知道互動流程，才能問「怎麼選動作」）
      └─→ V2: Q-table 機制（知道怎麼探索，才能問「怎麼記住學到的」）
           └─→ V3: Q-table 視覺化（知道 Q-table 存什麼，才能讀熱力圖）
                └─→ V4: 訓練曲線（知道怎麼看 Q-table，才能看整體進步趨勢）
                     └─→ V5: 連續狀態（離散概念鋪墊完，才能延伸到連續）
```

## 三、單組教學流程（12 支影片路徑）

```
Day 1
┌─ 前測（20 min）
├─ V0  What is RL — SAR Loop & Episode
├─ A0/B0  Platform Guide
├─ V1  How Agents Decide — ε-greedy & Hyperparameters
├─ A1/B1  MAB Demo  →  學生操作 MAB（T1）
├─ V2  How Agents Learn — Q-table & Update Rule
├─ A2/B2  Maze1D Demo  →  學生操作 Maze1D（T2）
└─ V3  Reading the Q-table Heatmap         ← Day 1 末尾預習

Day 2
┌─ A3/B3  Maze2D Demo  →  學生操作 Maze2D（T3）
├─ V4  Reading Training Curves
├─ A4/B4  Heli Demo  →  學生操作 Heli（T4）
├─ V5  Continuous State & Discretization
├─ A5/B5  Fighter Demo  →  學生自由體驗（T5，選做）
└─ 後測（20 min）
```

## 四、設計約束條件

1. **超參數覆蓋時機**：V0 不提超參數；V1 必須介紹 α / γ / ε 全部，因為 TA 從 MAB 開始即記錄學生是否正確設定超參數。

2. **Maze2D 跨堂設計**：V3 在 Day 1 末尾作為預習；Day 2 以 A3/B3 demo 開頭，直接銜接 T3 Maze2D 深探（Q-table 熱力圖路徑指認）。Maze2D 無「初探」獨立段落，學生在 Day 1 已接觸平台/notebook，Day 2 可直接進入深探。

3. **理論影片不露出另一組**：V0–V5 為共用影片，示範畫面必須使用兩組都能理解的通用素材（或分開剪輯），不能出現「在 Rein Room 裡…」或「在 Jupyter 裡…」的平台特定語言。

4. **示範環境選擇原則**：
   - SAR 示範 → Maze1D（人物移動，SAR 一一對應清楚）
   - ε-greedy 示範 → MAB（最能看到「不動」vs「亂跳」的行為對比）
   - Q-table 視覺化 → Maze2D（2D 空間才有路徑意義）
   - 訓練曲線 → Heli（先平後升的形狀最典型）
   - 連續狀態 → Heli/Fighter（第一個需要 bins 的環境）

5. **單組觀看影片數**：共用 6 + 專屬 6 = **12 支**；兩組合計需製作 18 支。

6. **影片時長目標**：理論影片 4–5 min；平台導覽 5–6 min；遊戲示範 3–4 min。
