## 撈回方式

如果需要把某個檔案從 archive 拉回根目錄使用：

```bash
git mv "_archive/原始章節docx/2.1 強化學習基本概念與教育潛力.docx" .
```

如果只是要查閱內容，直接在 archive 中開啟即可。
