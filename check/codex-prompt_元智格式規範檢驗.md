# Codex Prompt — 元智格式規範檢驗

> 用途：每次重大改動 `build_thesis.py` 或重新組裝 `論文_組裝.docx` 後，將下列 prompt 完整貼給 Codex（或其他 Agent），請其純審查、不動手，並產出 `check/codex-report_YYYY-MM-DD.md`。
> 本檔僅保存 prompt 本體，請勿在此檔內回應或加入檢核結果。

---

## Prompt 本文

```
任務：檢驗 論文_組裝.docx 是否符合元智大學論文格式規範（格式 A）

工作目錄：c:\Users\USER\論文 - RL平台教學成效

【檢驗對象】
- 主檔:論文_組裝.docx（由 build_thesis.py 從 md/ 組裝而成）

【規範來源】
- 元智格式規範/ 資料夾內的官方範本
- 元智格式規範/md/ 內的文字版規範說明
- CLAUDE.md 內也有摘要：字型（中文標楷體、英文 Times New Roman）、
  字級（正文 14pt、章名 20pt、節名 16pt、小節 14pt 粗體）、
  行距（正文 1.2x、摘要/誌謝/參考文獻 1.5x）、
  邊距（上 3.5cm、左 4cm、右 2cm、下 2cm）、
  章節層次（第一章 → 第一節 → 壹 → 一 → 1）

【檢驗項目】
逐項對比 docx 與規範，至少包括：
1. 頁面邊距（上下左右 cm 數）
2. 字型（中英文分別）
3. 字級（章名 / 節名 / 小節 / 正文 / 圖說 / 表格）
4. 行距（各區塊）
5. 章節編號層次（是否符合 第X章 / 第X節 / 壹、/ 一、 的傳統層次）
6. 圖表編號方式（是否連續、編號樣式是否符合）
7. 圖說、表說位置與字級
8. 段落首行縮排（中文段落 2 字元）
9. 頁碼位置與格式
10. 目錄、圖目錄、表目錄是否存在（如規範要求）
11. 任何其他元智格式 A 明文規定的細節

【若發現不符】
1. 不要動 docx
2. 不要動 md
3. 進入 build_thesis.py 找出造成不符的程式邏輯
   （例如：哪個 set_font / set_spacing / add_xxx 函數沒對齊規範）
4. 將分析結果寫入報告

【報告產出】
路徑：check/codex-report_YYYY-MM-DD.md（用今天日期）
格式：每項檢驗條目逐一列出，包含：
- 項目名稱
- 規範要求
- docx 實際呈現
- 是否符合（✅ / ❌ / ⚠️ 部分符合）
- 若不符，build_thesis.py 中對應程式位置與建議修法（不要直接改）

【嚴禁事項】
- 嚴禁修改 build_thesis.py
- 嚴禁修改任何 md 檔
- 嚴禁修改 docx
- 嚴禁修改 元智格式規範/ 內任何檔案
- 你的唯一輸出是 check/ 下的報告檔
- 任何「順手清理」「順手修正」的衝動都要忍住

【說明】
這是審查任務，不是修復任務。修復由人類事後決定。
你發現的問題越多越好，但動手是禁區。
```

---

## 使用方式

1. 確認 `python build_thesis.py` 已產出最新 `論文_組裝.docx`
2. 將上方 ``` 區塊內的 prompt 完整複製給 Codex
3. Codex 完成後，新報告會落在 `check/codex-report_YYYY-MM-DD.md`
4. 由人類審報告 → 決定是否要動 `build_thesis.py` 修補
