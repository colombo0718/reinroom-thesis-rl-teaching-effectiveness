## 【衝突 1】圖表編號方式

### 目前論文用法
```
圖 3-1  整體介面（截圖）
圖 3-2  通訊協定流程
圖 4-1  A/B 教學實驗流程
圖 5-1  概念測驗前後測分數箱型圖
...
圖 5-5  SUS 系統易用性箱型圖
```
**特點：** 章節.編號（連續編號，跨章節），共 19 張圖

### 元智格式 A 要求
```
圖 1   整體介面
圖 2   通訊協定流程
圖 3   A/B 教學實驗流程
圖 4   概念測驗前後測分數箱型圖
...
圖 19  SUS 系統易用性箱型圖
```
**特點：** 全文連續編號（1–19），不含章節資訊

### 決策選項
- **Option A（現狀保留）**：繼續用「圖 3-1、4-1、5-1...」，提供章節脈絡，不符元智標準但閱讀友善
  - 優點：讀者易於在文本定位圖片
  - 缺點：違反元智格式標準

- **Option B（元智標準）**：改為「圖 1–19」全文連續編號
  - 優點：符合元智正式規範
  - 缺點：失去章節資訊，讀者需翻目錄找位置；所有文本與圖目錄需批量改寫

### 老師決策：☐ 保留 A（現狀）/ ☐ 改用 B（元智標準）

## 【衝突 2】參考文獻格式

### 目前論文用法
```
(Goodfellow et al., 2016)
(蔡宗翰, 2021)
```
**特點：** APA 格式（Author, Year），文內引用後附完整參考清單

### 元智格式 A 要求
```
[1]
[23]
```
**特點：** 數字編號 [1]–[n]，文內引用對應參考文獻清單序號

### 決策選項
- **Option A（現狀保留）**：繼續用 APA (Author, Year)
  - 優點：讀者可直接看作者發表年，推論文獻新舊
  - 缺點：違反元智格式標準

- **Option B（元智標準）**：改用 [1]–[n] 數字編號
  - 優點：符合元智正式規範
  - 缺點：所有文內引用（30+ 處）需改寫；讀者需翻參考文獻頁才能確認作者/年份；全文參考文獻清單順序需調整

### 老師決策：☐ 保留 A（現狀）/ ☐ 改用 B（元智標準）

## 【衝突 3】章節編號層次

### 目前論文用法
```
第 1 章 緒論
  1.1 研究背景
    1.1.1 強化學習...
    1.1.2 教學平台...
  1.2 研究問題
    1.2.1 RQ1...
```
**特點：** 十進位編號（1.1、1.1.1），符合現代技術寫作習慣

### 元智格式 A 要求
```
第 一 章 緒論
  壹、研究背景
    一、強化學習...
    二、教學平台...
  貳、研究問題
    一、RQ1...
```
**特點：** 傳統中文層次（壹貳/一二/①②），符合中文學術論文傳統

### 決策選項
- **Option A（現狀保留）**：繼續用十進位編號
  - 優點：章節結構清晰；程式碼友善；符合 Markdown 與 Python 習慣
  - 缺點：違反元智格式標準；不符合中文論文傳統；需與格式 A 範本對齐後才能交卷

- **Option B（元智標準）**：改用傳統中文層次（壹貳/一二/①②...）
  - 優點：符合元智正式規範；符合中文學術論文傳統
  - 缺點：所有 md 檔案標題與引用文本（100+ 處）需改寫；build_thesis.py 輸出後需再次手動調整格式；維護困難

### 老師決策：☐ 保留 A（現狀）/ ☐ 改用 B（元智標準）
