## Phase 2：全文校稿（5/15–5/20，6 天）

### Task 2.1：AI 痕跡掃描 + 句式檢查

```bash
# 檢查清單
□ 對話式殘留（你、我、告訴我）
□ 模板殘留（[待填]、[XX]）
□ 過度套用詞彙（「綜合而言」、「值得指出」的出現次數）
□ 重複句式（「本研究」開場、「本節」開場）
□ 中英混用無空格（「强化學習learning」）
□ 標點符號一致性（西文標點 vs 中文標點）

# 掃描方法
VSCode Find 功能：逐一尋找疑似詞彙
- "綜合而言" → 計次，超過 3 次改寫其中 2 次
- "值得指出" → 計次，超過 3 次改寫其中 2 次
- "本研究" → 用「此研究」、「本項研究」等變換開場
- "本節" → 用「本小節」、「以下討論」替換

# 手動檢查（重點段落）
- 第一章 緒論（確認動機清晰，未過度承諾）
- 第四章 4.4.4 Treatment Fidelity（確認技術敘述不生硬）
- 第五章結果章節（確認未過度解讀數據）
- 第六章結論（確認推論範圍適當）
```

**工作量估計：** 2 天（2–3 小時/天）  
**驗證人員：** 最好找同學或朋友再讀一遍，確認無生硬處

## 風險與備忘

⚠️ **風險 1：格式決策耗時**
- 若老師要求「邊改邊看」，可能需多次迭代
- 建議：提前準備決策矩陣文件（已完成 ✅），便於快速執行

⚠️ **風險 2：參考文獻轉換出錯**
- BibTeX 的編號 ↔ 文內引用容易錯亂
- 建議：改寫後逐檔檢查，或寫個簡單 Python 腳本驗證對應

⚠️ **風險 3：校稿發現大問題**
- 若全文校稿發現重大AI痕跡或邏輯漏洞，可能需重寫 1–2 節
- 建議：邊校邊改，不要積累到最後

⚠️ **風險 4：附錄準備不足**
- 若研究倫理相關文件、問卷原件遺失，臨時找會困難
- 建議：5/20 之前先整理好所有原始材料
