圖 3-2　RL Lab 通訊協定訊息流程
平台（父頁面）與遊戲環境（子 iframe）透過 postMessage 雙向通訊
sequenceDiagram participant Game as 子頁面：遊戲環境（iframe） participant Lab as 父頁面：RL Lab 平台 Note over Lab,Game: 載入階段（每次 loadGame 觸發一次） Lab->>Game: questInfo
{ sessionId } Game->>Lab: gameInfo
{ stateInfo, actionInfo } Note over Lab,Game: 平台依此自動建立 Q-Table 結構與動作按鈕 rect rgb(255, 248, 230) loop 每一步互動：state-action-reward 迴圈 Lab->>Game: action
{ action: index } Game->>Lab: reward_state
{ reward, state, done, sessionId } end end Note over Lab,Game: 控制訊息（隨時可發） Lab->>Game: pause / accel
註：questInfo / action（平台 → 遊戲）；gameInfo / reward_state（遊戲 → 平台）。 done: true 時，reward 必須已包含終局懲罰（不另發 endEpisode）。 sessionId 由平台於每次 loadGame 遞增，遊戲需原封不動帶回，避免跨 session 訊息污染。 此設計使平台與遊戲在程式碼層面完全解耦——任何遵循此協定的網頁皆可作為訓練環境載入。
